Приложение является частью программно-аппаратного комплекса, который выводит данные с яндекс навигатора и mapcam.droid на штатный проектор KIA Sorento UM (prime).
Данное приложение захватывает данные, выводимые на экран смартфона, распознает их и передает по Bluetooth  в контроллер. 
Контроллер подключен к одной из CAN шин автомобиля, принимает данные от приложения и передает их через CAN шину в проектор. ПО контроллера идет отдельным проектом.

Приложение написано на Java. Запускается как ForegroundService.
Для захвата изображений используется MediaProjection
Для предварительной обработки изображений используется OpenCV
Для распознавания текста используется Tesseract 5 через
